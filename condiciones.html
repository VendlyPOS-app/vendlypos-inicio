El software no impone dependencia de servidores centrales propietarios para la venta diaria en mostrador ni comercializa información de sus operaciones.

1. Objeto y Descripción del Servicio

VendlyPOS es una suite tecnológica diseñada para optimizar las operaciones de comercio minorista y mayorista, integrando:

  • Terminal Punto de Venta (TPV/POS): Registro de ventas, control de inventario físico, catálogo de productos con códigos de barra y apertura/cierre de turnos de caja.
  • Arquitectura Multiplataforma Híbrida: Terminal maestro para Windows Desktop con sincronización en red local (LAN/mDNS) hacia terminales Android móviles dentro del mismo local comercial.
  • Módulos Comerciales Especializados: Control de cartera de créditos y cobros (fiados), programas de lealtad de clientes y alertas de abastecimiento crítico.
  • Catálogo Web Digital: Publicación opcional de productos en catálogo web para recepción de pedidos en tiempo real.
  • Facturación Electrónica DTE (El Salvador): Módulo opcional para transmisión de Documentos Tributarios Electrónicos conforme a la normativa vigente del Ministerio de Hacienda de El Salvador.
  • Copias de Seguridad en la Nube: Integración opcional y voluntaria con Google Drive API para resguardo automatizado de bases de datos.

4. Integraciones con Servicios de Terceros

VendlyPOS permite la interoperabilidad con plataformas externas para enriquecer sus funciones operativas:

A. Google Drive API (Copias de Seguridad)

El Usuario puede vincular voluntariamente su cuenta de Google Drive para subir y restaurar copias de seguridad de la base de datos comercial:

  • La integración opera bajo el alcance estricto https://www.googleapis.com/auth/drive.file.
  • VendlyPOS únicamente interactúa con los archivos y carpetas creados por la propia aplicación (directorio VendlyPOS_Backups). Bajo ninguna circunstancia la Aplicación tiene acceso para ver, leer, modificar o eliminar archivos ajenos almacenados en la unidad de Google Drive del Usuario.
  • El uso y la transferencia que hace VendlyPOS de la información recibida de las APIs de Google se apegan de manera rigurosa a la Política de Datos de Usuario de los Servicios de las API de Google, incluidos los requisitos de Uso Limitado (Limited Use).

B. Google Identity Services (OAuth 2.0)

El servicio de identidad de Google (alcances openid, email, profile) se provee exclusivamente para la validación administrativa de titularidad de la tienda en el catálogo web y la eventual recuperación de contraseñas de acceso administrativo, sin recolección de contraseñas ni acceso a comunicaciones privadas.

5. Conectividad y Período de Gracia Offline

VendlyPOS está diseñado para operar con alta disponibilidad en el mostrador sin requerir conexión continua e ininterrumpida a internet:

  • Operación sin Internet: El cobro en caja, la impresión de tickets físicos y el descuento de inventario funcionan de manera autónoma y local.
  • Verificación de Licencia y Período de Gracia: La Aplicación requiere conectividad a internet para su activación inicial y validaciones periódicas con la base de licencias de Firebase. La Aplicación otorga un período de gracia de 72 horas continuas offline. Transcurrido este plazo sin validación de red, el sistema requerirá conectarse a internet para reanudar operaciones.
